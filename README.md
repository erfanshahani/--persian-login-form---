# 🌐 Modern Persian Authentication UI

یک رابط کاربری مدرن برای **ورود و ثبت‌نام کاربران** که با **HTML5، CSS3 و JavaScript** توسعه داده شده است. این پروژه با تمرکز بر طراحی مدرن، تجربه کاربری (UX) و رابط کاربری (UI) ساخته شده و شامل امکاناتی مانند اعتبارسنجی فرم، حالت تاریک، نمایش/مخفی کردن رمز عبور، ذخیره اطلاعات کاربر و اعلان‌های تعاملی است.

---

## 🚀 تکنولوژی‌های استفاده شده

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome
- Toastify.js
- LocalStorage

---

## ✨ ویژگی‌ها

- رابط کاربری مدرن و واکنش‌گرا (Responsive)
- طراحی RTL مناسب کاربران فارسی‌زبان
- سیستم ورود و ثبت‌نام در یک صفحه
- انیمیشن نرم بین فرم ورود و ثبت‌نام
- اعتبارسنجی فرم با JavaScript
- بررسی صحت ایمیل
- بررسی حداقل طول رمز عبور
- نمایش پیام خطا برای هر فیلد
- نمایش و مخفی کردن رمز عبور
- قابلیت Remember Me
- ذخیره ایمیل کاربر با LocalStorage
- Dark Mode (حالت تاریک)
- اعلان‌های زیبا با Toastify
- دکمه ورود و ثبت‌نام همراه با Loading
- طراحی مدرن با Gradient و افکت‌های Hover
- آیکون برای تمامی فیلدهای فرم
- انیمیشن موفقیت پس از ورود یا ثبت‌نام
